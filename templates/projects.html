CampusOS

What started as a hackathon build turned into a full multi-agent campus management platform. I own the entire backend — nine AI agents orchestrated through FastAPI and LangChain's AgentExecutor, each handling a distinct slice of campus operations rather than one monolithic model trying to do everything.

Redis and Celery handle the async task queue so agent work doesn't block the API, MinIO gives S3-compatible storage for the files agents generate and retrieve, and Ollama serves the LLMs locally instead of routing every call through a paid API. The whole stack runs on Docker Compose, with a React 18 + TypeScript frontend a teammate built on top of it.

Agentic Content OS

A RAG pipeline built around agentic workflows instead of a single prompt-response loop. Retrieval and generation aren't one call — they're steps an agent decides to take, so the pipeline can re-query, re-rank, or branch depending on what the first pass turns up, instead of returning whatever the first retrieval happened to find.
